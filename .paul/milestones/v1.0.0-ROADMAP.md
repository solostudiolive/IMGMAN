## Milestone v1.0 — Eagle Parity (Phases 5–9)

Front-end transformation of the v0.1 MVP into an Eagle-class desktop app, plus a few new
backend features. The existing IPC namespaces (`library:*`, `items:*`, `tags:*`,
`folders:*`, `items:search`), per-library SQLite, and `imgman://` protocol were **reused**,
not rebuilt.

### Phase 5: Design system & shell ✅
Design-token theming (dark default + light, FOUC-safe), chrome-less per-platform title bar +
window controls, three-pane resizable/collapsible shell, settings modal.
- 05-01 tokens & theming · 05-02 title bar · 05-03 three-pane shell · 05-04 settings

### Phase 6: Eagle grid & content area ✅
Thumbnail-size slider + sort toolbar (renderer-side), three virtualized view modes
(grid/masonry/list — `@virtuoso.dev/masonry`), hover preview for GIF/video.
- 06-01 view toolbar · 06-02 masonry · 06-03 list view · 06-04 hover preview

### Phase 7: Selection & interaction ✅
Multi-select (click/ctrl/shift/marquee/keyboard), portal context menus, atomic batch ops
(delete/tag/move/rename), editable single + multi-item inspector (intersection semantics).
- 07-01…07-07 (multi-select, keyboard nav, marquee, context menus, batch ops, batch rename,
  multi-item inspector)

### Phase 8: Organize power features ✅
Saved searches / smart folders, no-dep color extraction + swatches, nearest-color color
search, find duplicates (SHA-256 `content_hash`; project's first schema migration). Plus
off-loop sidebar Tags + library rename.
- 08-01 saved searches · 08-02 color extraction · 08-03 color search · 08-04 find duplicates

### Phase 8.1: UI polish & Inter [INSERTED] ✅
Inter typeface (`@fontsource/inter`) + "refined dark, Eagle-like" restyle (flat near-black
palette, density, focus ring).
- 8.1-01 Inter + type/spacing · 8.1-02 color/contrast + component density

### Phase 9: Browser-extension collecting — ⏭️ DEFERRED to v1.1
External capture surface — companion browser extension + local receiver endpoint.
**v1.1 starting decisions (captured 2026-06-26):**
- Browsers: Chromium (Chrome/Edge) + Firefox (Manifest V3 both)
- Capture: right-click image + visible-page screenshot + drag-an-image
- Security: loopback-only receiver (127.0.0.1) + pairing token shown in app Settings
- Likely plan split: local receiver endpoint first (curl-testable, reuses Phase-2 import),
  then the extension.
