<objective>
## Goal
Add inline PDF viewing to the app — PDFs should render directly in the QuickPreview lightbox and the Inspector preview pane, instead of showing a placeholder icon. Uses the already-installed `pdfjs-dist` (v6), wired for the sandboxed, CSP-locked Electron renderer.

## Purpose
Phase 10 shipped real PDF *thumbnails* via `pdfjs-dist` (in `mediaThumbnail.ts`, main process, no worker). But there's no way to *view* a PDF's content: QuickPreview.tsx shows "No preview for PDF files yet" and the Inspector renders only `<img>` for previews. PDF is a first-class imported type (`ItemType` includes `'doc'` for PDFs) — viewing the content is the missing half of "real media thumbnails."

This plan also documents that **audio + video hover-play in grid cells are already complete** (Phase 13 / Phase 6) — no work needed, confirmed in Grid.tsx.

## Output
- `index.html`: CSP update to permit PDF.js worker (`worker-src`, `pdf.viewer` needs `imgman:` in `img-src`)
- `QuickPreview.tsx`: `<PdfViewer>` component for `type === 'doc'` items, integrated into the `Content` switch
- `Inspector.tsx`: inline PDF page-render in the preview click-to-enlarge lightbox (same `<PdfViewer>`)
- `preload/types.ts`: `PdfPage` type for renderer-side page navigation (first page, prev/next)
- `protocol.ts`: `original` handler already streams fine — no change needed, but documented
</objective>



