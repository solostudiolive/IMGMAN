<objective>
## Goal
Extract a **dominant-color palette** for image items and persist it, so colors are available for the
color-search slice (08-03) and visible to the user now. Palettes are computed during import
(piggybacking the existing sharp decode) and a **backfill** action populates already-imported items.
The inspector shows the palette as color swatches.

## Purpose
Second Phase-8 "organize power feature". Lays the data foundation (every image gets a stored palette)
that 08-03 color search will query. Decided approach (planning Q&A): a **no-dependency custom
quantizer** over downsampled sharp pixels — no new runtime dep and **no worker** (sharp's decode runs
off-thread, consistent with the Phase-2 "no worker pool" decision); and this slice is **extraction +
backfill + swatches only** (color SEARCH is its own slice, 08-03).

## Output
- `services/palette.ts` — `extractPalette(input: string | Buffer): Promise<string[]>`: a coarse-bucket
  quantizer returning up to N dominant colors as `#rrggbb` hex, ordered by coverage.
- Import wiring: `importFile` / `importImageBuffer` compute the palette from the sharp pipeline and
  store it (JSON in the existing `items.palette` column + in metadata.json). NO schema change.
- Backfill: `items:backfillPalettes` IPC (+ service) that fills `palette` for image items where it's
  NULL (reads each item's stored original/thumbnail), returning a count. A "Extract colors" button in
  Settings triggers it.
- Inspector: a Colors row rendering the palette as swatches (reads the existing `FullItem.palette`).
</objective>

  <name>Task 1: Palette quantizer + import wiring</name>
  <files>src/main/services/palette.ts, src/main/services/import.ts</files>
  <action>
    services/palette.ts — new. Export `const PALETTE_SIZE = 5` and
    `async function extractPalette(input: string | Buffer): Promise<string[]>`:
    - `const { data, info } = await sharp(input).resize(64, 64, { fit: 'inside', withoutEnlargement:
      true }).raw().toBuffer({ resolveWithObject: true })`. `info.channels` is 3 or 4.
    - Iterate pixels (stride = channels). If channels === 4 and alpha < 128, skip (transparent).
    - Quantize each channel to 4 bits: `bucket = (r >> 4)<<8 | (g >> 4)<<4 | (b >> 4)` (16 levels/ch);
      accumulate per-bucket count AND summed r/g/b (to average within the bucket for a truer color).
    - Take the top `PALETTE_SIZE` buckets by count; for each, color = round(sum/count) per channel →
      `#rrggbb` (lowercase, zero-padded). Return ordered most-dominant first. Empty input → [].
    - Wrap the whole thing so a throw is impossible to leak (caller also guards): on error return [].
    Add a small `paletteToJson(colors: string[]): string | null` = colors.length ? JSON.stringify :
    null (keep null semantics so "no colors" stays NULL in the column).

    services/import.ts —
    - `insertItem`: add `palette: string | null` to its param type and bind it (replace the hardcoded
      `NULL` for palette with `@palette`).
    - In `importFile` (image branch) and `importImageBuffer`: after the thumbnail succeeds, compute
      `const palette = paletteToJson(await extractPalette(absPath|buf))` inside the SAME try (so a
      sharp failure leaves palette null alongside width/height). Default `let palette: string | null =
      null` declared next to width/height.
    - Pass `palette` into both `record` (metadata.json) and `insertItem(...)`.

    Avoid: a new dependency; a worker; changing the thumbnail output; aborting import on extraction
    failure; touching schema.sql.
  </action>
