<objective>
## Goal
Switch the app typeface to **Inter** (self-hosted/bundled) and establish a typography & spacing
**scale** tuned for it — font sizes, weights, line-heights, and letter-spacing tokens — applied
globally through the existing token system. Foundation slice of Phase 8.1.

## Purpose
Inter is a screen-optimized UI typeface; adopting it (and tuning the scale for its metrics) is the
base layer of the requested UI refresh. Because typography is centralized (`--font-sans` in
tokens.css, applied in base.css), this is a token + entry-point change with app-wide effect and no
component edits. Color/contrast polish and component density/layout are the SEPARATE next slice (8.1-02).

## Output
- `@fontsource/inter` added as a dependency; its woff2 weights imported in the renderer entry
  (main.tsx) so Vite bundles them as same-origin assets (CSP/offline-safe — no CDN).
- `--font-sans` set to `'Inter', system-ui, …`; refined typography tokens (weights incl. regular/bold,
  a letter-spacing token, tightened heading line-height) and a reviewed spacing scale in tokens.css.
- base.css applies Inter-appropriate defaults (`font-feature-settings`, default letter-spacing).
</objective>

    tokens.css (:root) — refine the typography block for Inter:
    - Weights: keep `--fw-medium: 500` / `--fw-semibold: 600`; ADD `--fw-regular: 400` and

    - Line-height: keep `--lh: 1.45` (body); ADD `--lh-tight: 1.25` for headings/dense rows.
    - Letter-spacing: ADD `--ls-tight: -0.011em` (Inter reads better with slight negative tracking at
      UI/heading sizes) and `--ls-normal: 0`.
    - Sizes: keep the dense base (`--fs-md: 13px`) and the existing rungs; if any rung is off-scale,
      nudge for a coherent xs→xl progression (e.g. keep 11/12/13/15/20; optionally add `--fs-2xl: 26px`
      for future headings). Keep changes minimal and scale-consistent.
    - Spacing: review `--space-1..6` (4/8/12/16/24/32) for consistency; OPTIONAL add `--space-0: 2px`
      if a finer rung is useful. Do not remove/renumber existing rungs (components depend on them).

    base.css — apply Inter-appropriate global defaults on `body` (extend the existing rule, don't
    duplicate it): add `font-feature-settings: 'liga' 1, 'calt' 1;` (Inter ligatures/contextual) and
    `letter-spacing: var(--ls-normal);`. Keep the existing `-webkit-font-smoothing: antialiased` and
    `text-rendering: optimizeLegibility`.

    Avoid: removing/renaming existing tokens (would break components); per-component spacing/density
    changes (that is 8.1-02); color/contrast token changes (also 8.1-02).
  </action>
