<objective>
## Goal
Add the inspector/metadata panel and spacebar quick preview to the browse surface.
Selecting a grid item shows its full metadata in a side panel; pressing Space opens a
full-screen quick preview of the original (image full-size, video/audio with native
controls, a placeholder for other types).

## Purpose
Completes the "browse" half of the MVP value loop (collect → organize → search → **browse**).
The grid alone shows what you have; the inspector + quick preview let you actually
*look at* an asset and read its details — the core "second brain" payoff. This is the
last plan in Phase 3, after which the phase transitions.

## Output
- `items:get` IPC returning the full item record (all columns) for the inspector.
- `Inspector.tsx` — metadata panel rendered beside the grid.
- `QuickPreview.tsx` — full-screen Space-triggered overlay over the selected item's original.
- LibraryGate wired for a grid + inspector layout and global Space/Escape handling.
- CSP `media-src` opened to `imgman:` so video/audio originals can play in preview.
</objective>

<acceptance_criteria>

## AC-1: Inspector shows the selected item's metadata
```gherkin
Given a library with items is open and no item is selected
When the inspector renders
Then it shows a neutral empty state ("Select an item")
And when the user clicks a grid item
Then the inspector shows that item's preview thumbnail plus name, type/extension,
     dimensions (W×H when present), human-readable file size, rating, and
     created/imported dates, with source URL and note shown only when present
```

## AC-2: Inspector tracks selection and library changes
```gherkin
Given an item is selected and shown in the inspector
When the user selects a different item
Then the inspector updates to the new item's metadata
And when the active library is switched
Then the selection clears and the inspector returns to its empty state
```

## AC-3: Spacebar toggles a quick preview of the selected item
```gherkin
Given an item is selected
When the user presses Space
Then a full-screen quick-preview overlay opens for that item (page does not scroll)
And when the user presses Space again or Escape
Then the overlay closes
And given no item is selected
When the user presses Space
Then nothing opens
```

## AC-4: Quick preview renders by media type with no broken media
```gherkin
Given the quick preview is open
When the selected item is an image (or GIF)
Then the original renders full-size, letterboxed to fit the viewport
And when the item is a video or audio file
Then it plays via native <video controls> / <audio controls> served over imgman://original
And when the item is a font, doc, or other type
Then a large type placeholder with the file name is shown (no broken/empty media element)
```

## AC-5: items:get returns the full record safely
```gherkin
Given a library is open
When the renderer calls items.get(id) with a valid id
Then it receives the full item record (including duration_ms, palette, source_url, note)
And when called with an unknown id or while no library is open
Then it receives null (no throw across IPC)
```

    - In `src/main/services/items.ts`: add `interface FullItem extends Item` with
      `duration_ms: number | null`, `palette: string | null`, `source_url: string | null`,
      `note: string | null`. Add `getItem(id: string): FullItem | null` that returns null
      when `!isDatabaseOpen()`, else `SELECT *`-equivalent (list the columns explicitly,
      matching schema.sql order) `FROM items WHERE id = ?` and returns the row or null.
    - In `src/main/ipc/items.ts`: register `ipcMain.handle('items:get', (_e, id: string) =>
      getItem(id))`. Keep the existing `items:list` handler.
    - In `src/preload/index.ts`: add `get: (id: string) => ipcRenderer.invoke('items:get', id)`
      to the `items` namespace.
    - In `src/preload/types.ts`: add a `FullItem` interface mirroring the service type
      (extend `Item`), and add `get: (id: string) => Promise<FullItem | null>` to `IpcApi.items`.
    Avoid: widening `items:list` to the full record (keep the grid payload small); adding
    any new file-system or path surface (ids are validated only as a DB lookup key here —
    file access stays behind the existing imgman:// protocol).
  </action>
  <verify>npm run typecheck passes; grep shows `items:get` handler registered and `items.get` in preload + types.</verify>
  <done>AC-5 satisfied: items.get returns the full record for a valid id, null otherwise, no throw across IPC.</done>

          `new Date(ms).toLocaleString()`), Source (render source_url as text when present),

      Keep styling inline and consistent with the existing components (no new CSS deps).

      grid keeps scrolling. Do not change selection wiring (`onSelect={setSelectedId}`).
    Avoid: making the inspector editable (rating/note/tag editing is Phase 4 scope); adding a
    state-management library; refetching on every render (depend on selectedId only).
  </action>

<task type="auto">
  <name>Task 3: Spacebar quick-preview overlay</name>
  <files>src/renderer/src/QuickPreview.tsx, src/renderer/src/LibraryGate.tsx, src/renderer/index.html</files>
  <action>
    - Create `src/renderer/src/QuickPreview.tsx` exporting `QuickPreview({ item, onClose }:
      { item: FullItem | Item; onClose: () => void })` rendering a fixed full-viewport overlay
      (dark translucent backdrop, centered content, high z-index). Content by `item.type`:
        - image: `<img src="imgman://original/${id}">` letterboxed (maxWidth/maxHeight 100%,
          objectFit contain). GIF originals animate naturally.
        - video: `<video src="imgman://original/${id}" controls autoPlay>` letterboxed.
        - audio: centered `<audio src="imgman://original/${id}" controls>` plus the file name.
        - font/doc/other: a large type glyph + file name placeholder (reuse the Grid glyph set
          or an inline equivalent).
      Clicking the backdrop calls onClose. The component renders the original only; keyboard is
      owned by LibraryGate (below).
    - In `LibraryGate.tsx`: add `previewOpen` boolean state. Add a `useEffect` window `keydown`
      listener (active only while a library is open) that: ignores events when
      `e.target` is an input/textarea/contentEditable; on `e.code === 'Space'` calls
      `e.preventDefault()` and, only when `selectedId` is set, toggles `previewOpen`; on
      `Escape` sets `previewOpen` to false. Clear `previewOpen` whenever `selectedId` becomes
      null or the library changes. When `previewOpen && selectedId`, render `<QuickPreview>` —
      pass the already-selected item (look it up from `items` by id) and `onClose={() =>
      setPreviewOpen(false)}`.
    - In `src/renderer/index.html`: extend the CSP meta so `media-src` includes `imgman:`
      (add a `media-src 'self' imgman:` directive; keep the existing `img-src … imgman:`).
      Without it the renderer blocks video/audio loads from the imgman: scheme.
    Avoid: arrow-key navigation between items (defer — note in SUMMARY); a separate preview
    fetch (reuse the in-memory `items` row); leaving Space to also trigger the focused grid
    button (preventDefault handles this).
  </action>
