<objective>
## Goal
Add **List** as a third view mode: a virtualized details list where each item is one row showing a
small thumbnail plus columns (name · type/format · dimensions · size · rating). The 06-02 view-mode
control becomes a 3-way Grid / Masonry / List switch; the 06-01 sort + size controls drive it.

## Purpose
List/details is the third of Eagle's core view modes (grid/masonry/list). It completes the
"multiple view modes" Phase-6 deliverable and is the compact, information-dense way to scan a
library. It reuses react-virtuoso's `Virtuoso` (already a dependency) — no new package.

## Output
- `useGridView.ViewMode` extended to `'grid' | 'masonry' | 'list'` (persisted; validated).
- `ContentToolbar` gains a third (List) button in the existing view-mode segmented control.
- `Grid` renders a virtualized `Virtuoso` list of rows for List mode; Grid + Masonry paths untouched.
- `Grid.css` for list-row layout + hover/selected states (rows need pseudo-classes inline can't do).
</objective>
