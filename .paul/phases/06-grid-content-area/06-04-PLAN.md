<objective>
## Goal
Add **hover preview** to grid/masonry cells: hovering an animated GIF plays the animation, and
hovering a video plays it inline (muted, looping). A short hover-intent delay avoids firing while
the cursor sweeps across the grid or during scroll.

## Purpose
Final Phase 6 deliverable — Eagle's hover-to-peek behaviour, the last item in "hover preview for
GIF/video". It completes the Eagle-class content area (grid · masonry · list · size · sort · hover)
and closes Phase 6. Uses the existing `imgman://original/<id>` protocol — no ffmpeg, no new IPC.

## Output
- The shared `Cell` (used by grid + masonry) renders an animated/video preview on hover-intent for
  previewable items (GIF, video); reverts to the static thumbnail on mouse-leave.
- Hover-intent timer (~180ms) so transient pointer passes / fast scroll don't load originals.
</objective>
