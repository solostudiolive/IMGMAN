<objective>
## Goal
Finish the media story opened by v1.1: give audio files the same hover-preview treatment video already has in Cell, and upgrade find-duplicates from exact (SHA-256) to near-duplicate (perceptual hash) matching so re-encoded or resized copies are caught.

## Purpose
v1.1 shipped real thumbnails + duration for video/audio/pdf/font but deliberately left two gaps in STATE.md's deferred issues: (1) audio hover-preview (Phase 6's 06-04 explicitly says "List rows + a disable-toggle deferred" and audio hover is in PROJECT.md Should-Have), and (2) perceptual / near-duplicate detection (content_hash is exact-match only — re-encodes evade it). This plan closes both, turning "Rich Media Import" into "Smart Media".

## Output
- `mediaThumbnail.ts`: `extractAudioWaveform` exported so Cell can render audio previews
- `pHash.ts`: new perceptual-hash service (`pHashImage`, `pHashDistance`) using sharp pixel-resizing + DCT
- `items.ts`: `backfillPerceptualHashes()` + `findPerceptualDuplicateGroups()` mirroring the existing `backfillHashes`/`findDuplicateGroups` pattern
- `schema.sql`: new `phash` column on `items` (table_info-guarded migration, the v1.0 migration pattern)
- `ipc/items.ts`: `items:backfillPerceptualHashes` + `items:findPerceptualDuplicates` handlers
- `preload/types.ts`: `PerceptualDuplicateGroup` type
- `DuplicatesModal.tsx`: perceptual-duplicate tab (existing exact-dupes tab preserved)
- `Inspector.tsx`: audio duration row (renders `formatDuration(duration_ms)` for type==='audio')
</objective>
