<objective>
## Goal
Replace the v0.1 padded vertical stack with the real **Eagle three-pane shell**: a resizable,
collapsible **left sidebar** (library switcher + folder tree) · a **center** column (toolbar +
content grid) · a collapsible **right inspector** — all filling the frame beneath the custom
title bar, themed via tokens. Re-skin the in-pane components so the shell is visually coherent
in both dark and light.

## Purpose
The shell IS the Eagle look. Today the app is a scrollable page of stacked sections with a
3-column flex hack (`calc(100vh - 120px)`) and light-on-dark components. This plan gives the
app its desktop structure — the surface every Phase 6–8 feature (masonry, multi-select,
smart folders) plugs into.

## Output
- `AppShell` layout primitive (resizable/collapsible panes, persisted, with an always-visible
  toolbar carrying the pane toggles)
- `LibraryGate` recomposed to render into the shell; `App` goes full-bleed when a library is open
- `ThemeToggle` extracted to its own component, parked in the shell toolbar (final home: 05-04)
- Token re-skin of FolderTree, Inspector, SearchBar, ImportZone, and Grid chrome
</objective>

  <name>Task 1: AppShell — resizable/collapsible three-pane primitive</name>
  <files>src/renderer/src/components/AppShell.tsx, src/renderer/src/components/AppShell.css</files>
  <action>
    Create a presentational shell that fills its parent (height/width 100%, the parent gives
    it the area under the title bar). Props:
      interface AppShellProps {
        sidebar: React.ReactNode
        toolbar?: React.ReactNode      // center-column toolbar content (e.g. SearchBar + ThemeToggle)
        inspector?: React.ReactNode    // right-pane content
        children: React.ReactNode      // center content (the grid)
      }
    Layout = horizontal flex row, height 100%:
      [ sidebar ][ splitter ][ content column ][ splitter ][ inspector ]
    - sidebar: width = sidebarW px (0 when collapsed), background var(--color-bg-panel),
      borderRight 1px var(--color-border), overflow:auto.
    - content column: flex:1, min-width:0, vertical flex — a toolbar row on top
      (height var(--toolbar-h), borderBottom var(--color-border), background var(--color-bg-panel),
      display:flex align-items:center) then a content region (flex:1, min-height:0, overflow:auto,
      background var(--color-bg-content)).
      The toolbar row ALWAYS renders and contains, in order: a sidebar-collapse toggle button,
      the `toolbar` prop in a flex:1 middle, then an inspector-collapse toggle button — so the
      pane toggles are always reachable even when a pane is collapsed.
    - inspector: width = inspectorW px (0/hidden when collapsed or when `inspector` is null),
      background var(--color-bg-panel), borderLeft 1px var(--color-border), overflow:auto.

    Resizing: a thin splitter <div> on each inner edge. On mouseDown, record side + startX +
    startWidth, add document mousemove/mouseup listeners; mousemove computes the new width and
    clamps (sidebar 180–420, inspector 240–560); mouseup removes listeners. Splitters get
    `cursor: col-resize` and a hover highlight via AppShell.css. Hide a splitter when its pane
    is collapsed.

    Persistence: read initial sidebarW/inspectorW/sidebarCollapsed/inspectorCollapsed from
    localStorage (keys `imgman.shell.*`) with a guarded helper; write on change. Defaults:
    sidebarW 240, inspectorW 300, both expanded.

    Put structural/cursor/hover rules and the toggle-button styles in AppShell.css (token-based,
    like TitleBar.css). Toggle buttons use a chevron glyph («/» style) that flips with state.
    Avoid: pulling app state into AppShell (it's presentational); animating width on every
    mousemove with transitions (resize must be immediate — only animate collapse if cheap).
  </action>
  <verify>npm run typecheck:web passes; AppShell renders three regions; dragging a splitter changes a width; toggles set width to 0; values reappear after reload (localStorage).</verify>
  <done>AC-1 (structure) and AC-2 satisfied.</done>
</task>
